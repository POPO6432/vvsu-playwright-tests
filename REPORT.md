# Сценарии на сайте вуза: Playwright

**Сайт:** https://www.vvsu.ru/ (Владивостокский государственный университет)
**Страницы:** главная, /admission/, /sveden/, /news/
**Дата и время прогона:** 18.11.2026, 15:40
**Запуск:** `npm i` → `npx playwright install chromium` → `npx playwright test`
**Ограничения:** только чтение, без входа и отправки форм, один воркер, без нагрузки.

---

## Сценарий 1. Меню: «Поступление» ведёт в раздел абитуриента
- **Что проверяет:** после клика по «Поступление» адрес `/admission/` и на странице виден заголовок h1.
- **Почему важно:** это главный путь абитуриента; поломка меню отрезает от поступления весь трафик. Проверка дешёвая и стабильная, ручной прогон каждый релиз утомителен.
- **Шаги:** 1) открыть `/`; 2) закрыть баннер cookie; 3) кликнуть «Поступление» в меню; 4) проверить адрес; 5) проверить h1.
- **Ожидаемый результат:** URL оканчивается на `/admission/`, заголовок виден.
- **Как проверено:** `toHaveURL(/\/admission\/?$/)`, `toBeVisible()`; локаторы `getByRole('link', {name})`, `getByRole('heading', {level:1})`.
- **Результат прогона:** pass

## Сценарий 2. Меню: все пункты ведут на свои разделы
- **Что проверяет:** у каждого из 7 пунктов меню `href` указывает на свой раздел (`/admission/`, `/scientific/`, `/life/` и т. д.).
- **Почему важно:** меню на каждой странице; ошибка в одной ссылке тихая, глазами её находят не сразу. Проверка по всем пунктам занимает доли секунды.
- **Шаги:** 1) открыть `/`; 2) для каждого пункта найти ссылку по имени; 3) сверить `href`.
- **Ожидаемый результат:** все семь ссылок указывают на ожидаемые пути.
- **Как проверено:** `toHaveAttribute('href', regexp)`; локатор `getByRole('link', {name, exact: true})`. Проверяется инвариант (путь раздела), а не контент.
- **Результат прогона:** pass

## Сценарий 3. Подвал: «Сведения об образовательной организации»
- **Что проверяет:** из подвала главной открывается обязательный раздел `/sveden/`.
- **Почему важно:** раздел с обязательной информацией вуза требуется законодательством, его недоступность это риск для университета, а не просто неудобство. Путь короткий и стабильный.
- **Шаги:** 1) открыть `/`; 2) закрыть баннер cookie; 3) прокрутить к ссылке в подвале; 4) кликнуть; 5) проверить адрес и h1.
- **Ожидаемый результат:** URL оканчивается на `/sveden/`, заголовок виден.
- **Как проверено:** `toHaveURL`, `toBeVisible`; локатор `getByRole('link', {name})`.
- **Результат прогона:** pass

## Сценарий 4. Новости: главная → лента → новость
- **Что проверяет:** «Все новости» открывает `/news/`; в ленте есть ссылки вида `/news/<id>/`; первая из них открывается и показывает заголовок.
- **Почему важно:** новости самый часто обновляемый раздел, на нём чаще всего ломается вёрстка и шаблоны. Конкретные заголовки не проверяются (они меняются каждый день), проверяется связность пути.
- **Шаги:** 1) открыть `/`; 2) кликнуть «Все новости»; 3) убедиться, что лента открылась; 4) собрать ссылки на новости; 5) открыть первую; 6) проверить адрес и h1.
- **Ожидаемый результат:** ссылок на новости больше нуля, страница новости открывается по адресу `/news/<id>/` с заголовком.
- **Как проверено:** `toHaveURL`, `toBeVisible`, сравнение числа ссылок с нулём; локаторы по роли и тексту.
- **Результат прогона:** pass
