# Автотесты сайта ВВГУ

Восемь UI-тестов на Playwright проверяют, как посетитель сайта Владивостокского государственного университета переходит в разделы, читает новости и пользуется поиском. Проект продолжает набор из предыдущей практики. [Сайт ВВГУ](https://www.vvsu.ru/)

## Запуск

Из корня проекта на компьютере с Node.js 20 или новее и доступом в интернет выполните одну команду:

```sh
npm ci && npx playwright install chromium && npm test
```

После установки для повторного прогона достаточно `npm test`. Тесты выполняются последовательно в Chromium. Каждый получает новый контекст браузера. Результаты видны в терминале, а командой `npx playwright show-report` можно открыть HTML-отчёт последнего прогона.

## Что проверяем

| Сценарий | Ожидаемый результат |
| --- | --- |
| Ссылки верхнего меню | У каждого из семи пунктов свой ожидаемый адрес, в том числе у ссылки на внешний сайт ДПО. |
| Переход в раздел «Поступление» | Открывается `/admission/` с заголовком «Поступление». |
| Переход в раздел «Наука» | Открывается `/scientific/` с заголовком «Наука и инновации». |
| Ссылка из подвала | Открывается `/sveden/` с заголовком «Сведения об образовательной организации». |
| «Все новости» на главной | Открывается лента «Новости» с видимой карточкой публикации. |
| Открытие новости | Адрес статьи совпадает со ссылкой выбранной карточки, заголовок статьи совпадает с заголовком карточки. |
| Запрос без совпадений | На странице поиска сохраняется введённая строка и появляется сообщение «По вашему запросу ничего не найдено». |
| Очистка запроса | После удаления последнего символа поле пустое, ранее показанная выдача исчезает. |

Переходы в «Поступление» и «Науку» используют один параметризованный тест. Данные хранятся в массиве `sections` в [tests/vvsu.spec.js](tests/vvsu.spec.js). Для каждого пункта с заданным ожидаемым заголовком Playwright регистрирует отдельный тест. Заголовок новости тест берёт из карточки во время прогона, поэтому смена первой публикации не требует правок.

## Где менять локаторы и действия

| Page Object | Что в нём находится |
| --- | --- |
| [HomePage](pages/HomePage.js) | Верхнее меню, поиск в шапке, ссылка «Все новости», переход из подвала и закрытие уведомления о cookie. |
| [ContentPage](pages/ContentPage.js) | Общий элемент страниц разделов и публикаций — видимый заголовок первого уровня. |
| [NewsPage](pages/NewsPage.js) | Открытие ленты, выбор первой карточки, чтение её заголовка и переход к статье. Использует заголовок из ContentPage. |
| [SearchPage](pages/SearchPage.js) | Поле запроса и область результатов на странице поиска, открытие с заданным запросом и очистка поля. |

Проверки навигации и новостей находятся в [tests/vvsu.spec.js](tests/vvsu.spec.js), проверки поиска — в [tests/search.spec.js](tests/search.spec.js). Например, при изменении вёрстки карточки достаточно обновить её локатор в NewsPage. Ожидаемые результаты и все вызовы `expect` находятся в тестах.

## Что оставили для ручной проверки

- Вход в личный кабинет требует тестовой учётной записи и доступа к закрытой части сайта.
- Отправка обращения или заявления создаёт реальную запись у университета. Такой сценарий можно проверить на учебном стенде с тестовым получателем.
